# B. W. Payne & Sons v. Noon

## Majority (Per Curiam:)

Per Curiam:
No written points were presented to the court. The mere omission to refer to all the evidence is not a sufficient cause for reversing the judgment. The main evidence which controls the case was properly presented to the jury in a correct manner. We see no error in the record.
Judgment affirmed in each case.
