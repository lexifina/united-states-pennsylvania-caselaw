# Lucas Coal Co. v. Hunt & Connell

## Majority (Per Curiam:)

Per Curiam:
The alleged written contract sustains so important a relation to the defense of the defendant below that we think the learned judge committed no error in holding that it should have been, fully set forth in the affidavit of defense.
Judgment affirmed.
